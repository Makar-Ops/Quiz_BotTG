# 🧠 IQ Quiz Bot (Telegram)

Асинхронный Telegram-бот для проведения интеллектуальных викторин. Написан на Python с использованием библиотеки `aiogram 3`.

> **Статус:** Это базовая версия (MVP). В планах — добавление реальной базы вопросов.

## 🚀 Функционал
- **База данных на 10 000 вопросов** (SQLite).
- **Умная выборка:** Бот выбирает 30 случайных вопросов из базы при каждом запуске.
- **Таблица лидеров:** Сохранение рекордов пользователей в базе данных.
- **Inline-меню:** Удобное управление через кнопки.

## 🛠️ Технологии
- **Язык:** Python 3.14
- **Библиотека:** Aiogram 3
- **База данных:** SQLite3

## 📂 Структура проекта
- `botQuiz.py` — основной код бота.
- `db.py` — скрипт для генерации тестовой базы данных.
- `.gitignore` — файл для исключения лишних файлов.
